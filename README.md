
# Scribe: AI-Powered Secretary Assistant

[![CI](https://github.com/Stumpwiz/scribe/actions/workflows/ci.yml/badge.svg)](https://github.com/Stumpwiz/scribe/actions/workflows/ci.yml)

**Scribe** is an AI-based assistant tailored to automate the secretarial workflows of a Residents Council or similar governance body. It uses CrewAI agents and tools to monitor an inbox, classify incoming reports, extract relevant content, and support agenda and minutes preparation.


## 🛠️ Key Features

- **Inbox Monitoring**: Uses Gmail API to retrieve unread messages with minimal permissions.
- **Email Classification**: Heuristically filters for relevant committee reports.
- **Attachment Extraction**: Organizes and saves report files.
- **Structured Output**: Generates a success flag, classification result, and output folder paths.
- **Extensible Tools**: Easily extendable tool registry (`TOOL_REGISTRY`) system.
- **PDF Agenda Generation** *(upcoming)*: Uses LaTeX templates to generate printable agendas.

---

## 🔒 Security Considerations

- **OAuth Scopes**: Only the `https://www.googleapis.com/auth/gmail.readonly` scope is used, ensuring the app can only *read* emails, not send or delete.
- **No Cloud Storage**: All files are stored locally or on the private server where the app is deployed.
- **Minimal Attack Surface**: No open ports; email processing is initiated manually or via cron job.
- **Audit Trail**: Logs every step (Inbox check, classification, etc.) for full transparency.
- **Safe Transfer**: App is designed to be hosted in a secure cloud (e.g., IONOS VPS), with isolated access.

---

## ☁️ Cloud Hosting Readiness

- Lightweight design suitable for a 2 vCPU / 2GB RAM VPS.
- Can be configured as a cron job or background service.
- All assets are filesystem-based—no database dependency.

## ✅ Getting Started

1. Clone the repo to your machine or server.
2. Create virtual environment and install requirements:
    ```bash
    python -m venv .venv
    source .venv/bin/activate  # or .venv\Scripts\activate on Windows
    pip install -r requirements.txt
    ```
3. Install the package in editable mode to enable the console script:
    ```bash
    pip install -e .
    ```
4. Authenticate Gmail using `google_auth_helper.py` (token saved locally).
5. Run the inbox agent via the CLI:
    ```bash
    scribe-ingest
    ```

## Publishing committee minutes

Committee minutes are converted from DOCX to PDF and placed in the MRRA digital
archive. The archive is the authoritative record; `index.html` receives only a
link to that archived PDF. LibreOffice must be installed and available as
`soffice` (or `libreoffice`) on `PATH`.

Preview the conversion and proposed link change (the default is a dry run):

```bash
uv run python -m src.scribe.cli.archive_committee_minutes \
    --committee SE \
    --month 2026-07 \
    --source "/path/to/minutes.docx" \
    --site-root "/path/to/mrra"
```

Apply the archive and website changes:

```bash
uv run python -m src.scribe.cli.archive_committee_minutes \
    --committee SE \
    --month 2026-07 \
    --source "/path/to/minutes.docx" \
    --site-root "/path/to/mrra" \
    --apply
```

An existing destination PDF is refused unless `--force` is also supplied.
